### A8 的量法

⚠️ **量渲染後的 HTML，而且只量同一個區塊元素內部的換行。**
直接對 `.md` 原始檔或整份 HTML 做 grep 會量到大量假陽性：區塊與區塊之間的換行
（`</p>` 與 `<h2>` 之間那種）不會渲染成空格。同樣的教訓記在 `AI-Writing-Skill` 的
`docs/待辦總覽.md`。

量法：`npm run build` 之後，逐一取出 `dist/` 每個 `<p>`、`<li>`、`<td>`、`<th>`、
`<h1>` 到 `<h6>`、`<blockquote>` 元素，去掉行內標籤，數「中文字＋換行＋中文字」的配對。
不要跨區塊數。
