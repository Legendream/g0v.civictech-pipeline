# 站①驗收條件：批次四（視覺改版）

寫於 2026-09-08。依據是 Claude Design 交出的設計交接包
（`README.md` ＋ 五份 `.dc.html` 視覺參考稿 ＋ 15 張截圖）。

這一批只換視覺，**不動任何一句既有文案**。留言區（批次三）不在這一批裡。

## 這一批要解決什麼

原站的 `table`／`pre`／`code`／`h3`／`ul`／`ol`／`blockquote` 從來沒有定義樣式，
手機上程式碼區塊與表格會被裁切。長文從頭到尾單一底色，讀者找不到自己在哪一段。

## 動工前定案的三件事

| 議題 | 決定 | 理由 |
|---|---|---|
| 內容檔格式 | `.md` 改成 `.mdx` | 滿版交錯色塊、圖示、卡片、長條圖、時間軸、手風琴，純 Markdown 加元素選擇器做不出來。`.mdx` 保留「一頁一個檔、檔名即網址」，版面元件抽到 `src/components/` |
| 英數字型 | 不用 Google Fonts，退回系統字型堆疊 | 會產生外部請求，跟關於頁「不載入任何第三方追蹤碼或分析工具」那句衝突。Inter 只在英數字上看得出差異 |
| 深色模式 | 跟隨系統 ＋ 手動切換鈕，兩者都留 | 原站行為不退步，設計稿的切換鈕也保留 |

## 一、既有九條規則不能破

交接包的 README 列了九條沿用限制，這一批不打算破任何一條。

| # | 條件 | 怎麼驗 |
|---|---|---|
| A1 | 版型檔與元件檔裡沒有寫死的中文介面字串，全走 `zh.json` | `grep -rnP '[\x{4e00}-\x{9fff}]' src/layouts src/components` 只命中註解 |
| A2 | 沒有任何第三方資源請求（字型、CDN、追蹤碼） | `grep -rn 'https://' dist/*.html dist/zh/*.html` 只剩內容裡的外部連結，`<head>` 無 `link rel=stylesheet` 指向外網 |
| A3 | 深色模式可用：預設跟隨系統，手動鈕可覆蓋，重新整理不還原、不閃爍 | 瀏覽器切系統深色看一次；按鈕切一次再重整看一次 |
| A4 | 網址仍帶 `/zh/` 前綴，導覽仍由 `zh.json` 的 `nav` 陣列產生 | 五個路由逐一開；`zh.json` 加一筆 nav 會多出一個項目 |
| A5 | `.skip`（跳到主要內容）與 `aria-current="page"` 都還在 | Tab 鍵第一下看得到跳連結；當頁導覽項有 `aria-current="page"` |
| A6 | 關於頁維持原本留白，這一批不加留言區 | 人工讀過 |
| A7 | 全站文案無破折號 | `grep -n '—' src/pages/zh/*.mdx src/i18n/zh.json` 無命中 |
| A8 | 頁首有語言切換器佔位（`<span>`，字串在 `zh.json`），導覽項目數量不寫死成四等分 | 檢視原始碼；`zh.json` 的 nav 增減一筆，版面不破 |
| A9 | 加英文版仍只需三個動作（`LOCALES` 加代號、加 `en.json`、加 `src/pages/en/*.mdx`），不必改版型 | 用拋棄式測試檔實證，驗完刪掉 |

## 七、這一批怎麼走五站

站③與站④的份量跟寫作類交付物不同，2026-09-08 決定如下。

- **站③自我驗證加重**：驗收條件超過一半（C2–C7、C9、D1–D8、E1、E2、E5）只有在瀏覽器
  裡真的跑起來才驗得到，讀原始碼一律驗不出來。逐頁跑 375／768／1280 三個寬度、
  亮色與暗色兩種模式、鍵盤走一遍。
- **站④縮到看得見的範圍**：`/code-review` 照跑，掃 diff 抓正確性 bug。
  `acceptance-reviewer` 只有 Read／Grep／Bash／WebFetch，**看不到畫面**，
  量不了 375px、看不出對比度、按不了 Tab；硬派它驗視覺只會憑 HTML 猜。
  因此只給它「規則遵守（第一節）＋文案沒漂移（第二節）」這兩塊，
  材料是改版前後的純文字 diff 與驗收條件，不給實作過程。
- **`number-auditor` 這一批省掉**：這批沒有新算任何數字，全部沿用現有文案；
  唯一的新數字 47／54／26 已追到研究報告正本。站④的文字 diff 直接證明
  「沒有任何數字被動過」，比重算一次更強。
- **最後一關是 Claire 自己的眼睛**：視覺改版，按 merge 前用手機開一次預覽網址。
