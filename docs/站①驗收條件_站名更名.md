# 站①驗收條件：站名從「行動指引」改為「經驗寫作流程」

2026-09-10 定案。

## 為什麼改

舊站名「臺灣公民科技行動指引」把產物掛在招牌上，但這個站的實體是方法論與流程，
行動指引只是流程的輸出。而且「行動指引」在這個生態系裡已經是既有的文類名稱
（台灣公民科技資料庫上的分類、g0v HackMD 上的《公民科技行動指引 Guide》索引），
舊站名會被讀成「那些文章的集合站」或「台灣公民科技的全盤入門」，兩種都不是這個站。

新站名把招牌換成流程，「臺灣公民科技」留在名字裡當領域標記，
守住 `CLAUDE.md` 那條「不要變成一個沒有主角的方法論網站」。

**新站名：臺灣公民科技經驗寫作流程**
