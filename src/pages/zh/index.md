# 把社群經驗化為持續運作的解法：人機協同寫作流程

許多社群專案累積了解法與踩坑紀錄，但往往因動筆與整理成本過高而難以傳承。當核心成員淡出，後續參與者往往只能重複摸索。

這套方法論從真實問題洞察出發，以公民科技為示範領域。透過結構化的人機協同機制，協助專案以更低的時間負擔，產出結構清晰、附帶完整事實查核軌跡的行動指引。

## 為什麼需要這套流程

在 127 位問卷受訪者中，有 26 人只聽過或看過公民科技、尚未實際接觸。問及這 26 人還沒參與的原因：

- **62%（16 人）** 不知道有哪些專案或議題可以參與
- **54%（14 人）** 身邊沒有人帶，怕融不進去或幫不上忙
- **50%（13 人）** 不知道怎麼加入，找不到入口
- **35%（9 人）** 覺得要會寫程式，技術門檻太高

調查結果顯示，阻礙參與的前三名原因都在於缺乏資訊與指引，技術門檻位居第四。目前[台灣公民科技資料庫](https://civictech.tw/)已收錄超過 350 個專案，但[行動指引](https://civictech.tw/#know-how)僅有 31 篇。這套流程正是為了解決經驗難以傳承、動筆門檻過高的問題。

## 三大核心特色

### 1. 明確的人機分工
素材整理、結構大綱與初稿撰寫交由 AI 處理；核心主張、風格取捨、關鍵事實判定與發布決策由你親自把關。

### 2. 附帶完整稽核軌跡
產出不只是一篇文章，還同步包含事實查核總表、依據等級標註與引用清單，讓每項陳述都有出處可查。

### 3. 開箱即用與開源授權
整套流程以 CC BY 4.0 授權開源釋出。使用 claude.ai Pro 方案並開啟 Code execution 設定後，在瀏覽器上傳 zip 壓縮檔即可啟用 Skill 進行協作。

[了解 8 個協作階段如何運作](/zh/pipeline/)

## 快速開始

你可以依照平常使用的工具，挑選適合的上手路徑：

- **瀏覽器直接使用（免寫程式）**：下載 zip 壓縮檔並上傳至 claude.ai，全程於瀏覽器操作。
- **本機終端路徑**：使用支援本機檔案的工具直接載入專案資料夾。

## 方法與領域適用性

公民科技是這次研究與流程設計的示範領域，但這套人機協作寫作方法本身與特定領域無關。要寫的是產業報告、社區紀錄還是內部文件，同一套走法都成立。
